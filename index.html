01About me

From breaking Windows to building AI agents.

Hrithik Lega

AI Developer · Cario, Melbourne · --:--

It started with games. Chasing more performance, I tweaked everything — even registry values I shouldn’t have touched — until Windows broke. Fixing it through YouTube, XDA guides and forum threads is when I became obsessed with computers. Beautiful, animated websites pulled me into code; AI that writes code from my specs let me pour my energy into design and logic.

Today I build AI agents, browser-automation microservices and API integrations that run in production — self-verifying, idempotent and fail-loud. I want every build to make a measurable impact.
